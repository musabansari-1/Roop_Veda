## 🔑 Key Concepts

### Pages Structure
```
All pages follow pattern:
├─ Header (company info + title)
├─ Content sections
├─ CTA section (call-to-action)
└─ Footer (company info + links)
```

### Design System
```
Colors: Forest (text), Ember (accent), Sand (background)
Fonts: Fraunces (display), Space Grotesk (body)
Components: Surface cards, Buttons, Icons, Grids
```

### Navigation
```
Home (/) → About, Privacy, Terms, Refund, Contact
Quiz (existing) → Links from all pages
Dashboard (existing) → Preserved, unchanged
```
