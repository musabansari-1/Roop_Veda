## Color Scheme Integration

| Element | Color | Usage |
|---------|-------|-------|
| Backgrounds | White/Surfaces | Cards, sections |
| Primary Text | Forest Green | Headings, body text |
| Secondary Text | Forest/60 | Lighter text, descriptions |
| Accents | Ember Orange | Icons, highlights, important CTAs |
| Borders | Forest/15 | Subtle card borders |
| Gradients | Amber to Orange | Call-to-action sections |

## Responsive Breakpoints

| Screen Size | Layout |
|------------|--------|
| Mobile (< 768px) | Single column, stacked cards |
| Tablet (768px - 1024px) | 2-column grids |
| Desktop (> 1024px) | 3-4 column grids, full layout |

## Interactive Elements

1. **FAQ Accordion**
   - Click to expand/collapse
   - Arrow icon rotates 180°
   - Smooth transitions

2. **Plan Cards**
   - Hover scale effect (1.05x)
   - Most loved plan scales permanently (lg:scale-105)
   - Ring border on popular plan

3. **Navigation Links**
   - Hover state: background color change
   - All links use Next.js Link component
   - Internal: Relative paths (/quiz, /about, /#about)
   - External: mailto and anchor links

4. **CTA Buttons**
   - Primary: Forest green background
   - Secondary: Border with forest text
   - All have hover animations
   - Shadow glow effect on hover
   - Lift effect (-translate-y-0.5) on hover
